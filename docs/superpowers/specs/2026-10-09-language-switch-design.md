# 面板中英文切换设计

## 目标

在乌合之众活动面板中提供中文和英文界面。用户可在设置页切换语言，选择立即作用于整个面板，并在下次打开时保留。

## 用户体验

- 设置页外观区域提供“中文 / English”语言选择。
- 首次打开默认中文；选择保存到本机浏览器的 `localStorage`。
- 切换后立即更新活动页、子代理页和设置页的内置界面文案，并同步更新根 HTML 元素的 `lang` 属性。
- 清理本机数据时清除语言偏好，使界面恢复中文默认值。
- 任务描述、模型答复、用户自定义路线/分组/角色名称及后端原样返回的错误详情不翻译；其周围的固定界面标签保持当前选择的语言。

## 实现方案

在现有单文件 `laowu-sidebar.html` 中维护轻量的中文、英文文案表和翻译函数。静态外壳、活动与子代理界面、设置页模板及由前端生成的按钮、状态、提示和对话框都使用当前语言文案。语言选择沿用现有本地偏好存储方式，不新增后端协议、依赖或配置文件。

## 验收标准

1. 无语言偏好时显示中文。
2. 在设置页选择 English 后，活动、子代理和设置三个视图中的内置文案切换为英文，`document.documentElement.lang` 为 `en`。
3. 刷新或重新打开面板后仍显示英文；切回中文后 `lang` 为 `zh-CN`。
4. 用户输入和动态任务内容保留原文。
5. 清理本机数据后语言偏好清除并恢复中文。
6. 现有主题、字号、侧栏宽度、路线配置和任务行为不受影响。

## 测试范围

扩展现有侧栏行为测试，覆盖默认语言、切换与持久化、根 `lang` 属性和清理偏好；运行相关测试及项目离线测试入口。
