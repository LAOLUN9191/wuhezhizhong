# 发布说明

公共源码由根目录 `release-files.json` 明确列出；新增公开文件时同时更新清单。内部审查记录、个人 Agent 规则、真实配置、凭据、状态、日志和旧包不是发行输入。`.gitignore` 不能替代发布清单，也不会移除已经跟踪的内部文件。

发布构建器要求清单保留完整运行文件与两组测试文件。candidate 模式会拒绝符号链接和硬链接；清单校验还会拒绝常见秘密、凭据、密码、token、API key、auth/cookie 数据文件名、`.env*` 文件及私钥/证书扩展名。它仍允许普通公开 XML 和代码/说明文件，只拒绝明确的本机凭据文件名（如 `keys.xml`）。这些规则只能拦截已知模式；每次候选仍需检查清单与包内容，不能用路径过滤代替内容审查。

## 验证与准备

首次公开采用干净源码仓库：只导入已审核公共清单中的文件，保留私人开发仓库及其历史。不得直接推送私人开发仓库，或把内部目录通过 `git add .` 混入公开仓库。公开仓库建立后，所有新增提交仍需检查内容及作者邮箱。

在 Windows、Python 3.11+ 环境运行 `python -B tools/run_tests.py`。Node.js 用于面板 JS 行为检查；浏览器功能另外依赖支持内置 WebSocket 的 Node.js（`node -p "typeof WebSocket"` 应输出 `function`）和 Chrome/Edge。完整离线测试使用合成配置与凭据；若测试入口发现 0 项测试会以失败退出。离线测试不代表真实 provider 已验收。

发布前在目标 Codex 版本验证：stdio 连接与面板载入、外部 provider 任务、只读角色、1–8 代理并发限制与排队、排队及执行中取消、长结果分页、保留后重启、根据验收结果续聊同一会话、续聊权限撤销、原生回退显式开关。填写实际版本和结果；没有验证的项目保留为未验证。模型列表查询成功不能替代一次实际工具执行成功。

逐项记录见 [发布验收表](acceptance.md)，支持范围见 [兼容性说明](compatibility.md)。CI 会在 Windows/Python 3.11–3.13 上运行离线检查；只有实际 Actions 运行成功后才能标记云端通过。

公开前还需运行秘密扫描、检查第三方代码来源、启用私密漏洞报告，并核对 README、许可、贡献指南与版本说明。秘密扫描应覆盖公开工作树和全部公开历史；扫描无命中也不能代替人工审查。不要公开未脱敏扫描报告。

## 待审候选包

工作区有未提交改动时，仅制作明确标识的候选包：

```powershell
python -B tools/build_release.py --candidate --output .release/wuhezhizhong-candidate.zip
```

它只读取显式清单，包含 `RELEASE-MANIFEST.json`，记录候选身份、基准 commit 和每个公开文件的 SHA-256。候选包不是正式版本。工具拒绝覆盖现有文件；需要重新构建时使用新的输出文件名。

## 正式源码包

将已审核的源码、测试、公开文档和发布清单纳入同一个 commit；确认相关新增文件均已跟踪。然后从该 commit 或 tag 构建：

```powershell
python -B tools/build_release.py --ref <reviewed-commit-or-tag> --output .release/wuhezhizhong-source.zip
```

正式模式读取所选 Git ref 的清单和文件，不混入当前工作区内容。旧 ref 没有完整清单或必需入口时拒绝构建。输出中的文件按确定顺序和固定 ZIP 时间戳写入，便于比较相同来源的构建结果。

“正式模式”仅指从确定 commit 构建的来源格式，不表示真实集成已经验收。尚未完成验收的包必须继续标为候选，不打稳定版本标签。将包解压到没有本机配置与内部文件的新目录，重新运行 `python -B tools/run_tests.py`，确认公共源码自包含。

GitHub 仓库公开时，Git 历史仍需独立审核。只将文件排除出 ZIP 不会清除历史中的内部材料。安全报告渠道和正式发布由维护者设置；发布工具不会推送仓库或上传文件。

## 本机残留

测试统一使用 `.test-*` 前缀，正常结束会清理本轮目录。旧 `.probe*`、`tmp*` 等目录须先核对归属、符号链接及占用情况再删除。`keys.xml`、`user_config.json` 和任务状态属于用户数据；不要仅根据目录名推断它们可以删除。旧发布包可保留在忽略的 `.release/` 目录中作为历史对照。
